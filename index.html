🔐 Simulación de acceso a una galería

Esta página sirve para aprender cómo funciona el acceso autorizado a fotografías desde un navegador. No obtiene fotografías automáticamente ni puede acceder silenciosamente a toda la galería.

Todavía no has seleccionado ninguna fotografía.

🔒 Seguridad:
La imagen seleccionada solamente se muestra en este navegador. Este laboratorio no sube ni envía la fotografía a ningún servidor.

¿Qué estás aprendiendo?

  • Un enlace puede abrir una página web.
  • El navegador no entrega automáticamente toda la galería a una página.
  • El usuario debe realizar una acción explícita para seleccionar un archivo.
  • Los permisos y selectores de archivos son mecanismos importantes de seguridad.
